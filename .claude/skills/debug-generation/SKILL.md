# 생성 사고 진단 플레이북

원칙: **추측으로 두 번 이상 고치지 말 것.** 층별로 실측해 격리 — 서버(curl) → 클라 파서(브라우저에서 실함수 호출) → 렌더(하네스). 유저 화면과 내 테스트가 다른 지점을 보고 있으면 "고쳤는데 안 됨"이 반복된다.

## 증상 → 진단 순서

### "생성이 N장에서 끝남 / 하다 말아"
1. 서버: `stream:true` curl로 SSE 받아 조립 → 장수 세기. 10장 오면 서버 무죄
2. 클라: "Done! N slides" = `composeDeck`이 N장짜리를 성공 반환한 것 — 스트림 순단 + 관대한 파서가 조각을 살린 케이스. LOCK10 재시도(llm.js·studio 두 곳)가 작동하는지 콘솔 로그 확인
3. 관대한 파서(`_repairParse`)는 잘린 JSON도 "성공"시킨다 — 길이 검증이 방어선

### "번역 실패 (Content translation failed)"
1. 서버: `/translate` curl (슬라이드 3장 청크 + 사이트 통짜 **둘 다** — 경로가 다름!)
2. 서버 OK면 클라 파서: `{payload:{...}}` 래핑 유무(모델별로 다름 — 양쪽 수용이 정답이었음), `_translateOne` 직접 호출로 재현
3. 페이로드 비만: 업로드 dataURI가 실려 토큰 초과(`_noHeavy` 확인)
4. 출력 상한: 웹 통짜는 잘림 위험 — max_tokens 확인

### "이미지가 사라짐 / 처음엔 보였다가"
1. 데이터: img 필드값 실측(fixBrand 오염? URL? 빈 값?)
2. 경로: file:// 환경이면 aurl이 프로드로 강제되는지, onerror 폴백 동작
3. "생성 완료 순간 사라짐" 전과 = fixBrand가 파일명까지 치환(_FB_SKIP로 해결됨)

### "언어가 섞임 / 리스트랑 본문이 다름"
1. 렌더 경로별 `_clang` 동봉 확인(본문·썸네일·라이브·뷰어 — 하나라도 빼먹으면 그 경로만 기본 언어)
2. 잠금/폴백 언어는 내용 비율 판정인지
3. `grep "|| '[가-힣]" app/packs.*.js`

### "글자가 얇음 / 글자마다 폰트 다름" (zh·ja)
- 폰트 스택에 Noto Sans SC/JP가 **1순위**인지(Pretendard가 흔한 한자 일부 보유 → 뒤에 있으면 글자별 혼합)
- 라이트 300은 한자에서 실낱 — 랜딩 500·PPT 400 상향 규칙 적용됐는지

## 유저 재현 요청 시

- 스크린샷은 **전체 창**으로(크롭은 오판 유발 — 포커스 링을 버튼 모양으로 착각한 전과)
- 실패 화면만 말고 **좌측 채팅 로그**까지 — 어느 단계에서 죽었는지 나옴
- 수정 배포 후엔 반드시 탭 강력 새로고침 안내(열린 탭은 옛 코드)
