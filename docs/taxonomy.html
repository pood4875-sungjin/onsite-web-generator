제품소개 웹사이트 섹션 유형 분류

페이지 유형이 아니라 화면 구성 방식·표현 형태 기준. 대분류 → 섹션 유형 → 표현 방식 → 레이아웃 → 구성 요소.

명명 규칙  [대분류]-[콘텐츠목적]-[표현방식]-[레이아웃]
예: HERO-PRODUCT-VIDEO-FULL · FEATURE-ICON-GRID-3COL · PRODUCT-CARD-GRID-3COL · PROCESS-STEP-HORIZONTAL-4
원칙: 2·3·4단은 목적이 아니라 레이아웃 속성 → 별도 유형으로 만들지 않음. 표현형(이미지·아이콘·카드·리스트·캐러셀·영상)은 Variant로 확장.
