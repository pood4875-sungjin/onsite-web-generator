웹페이지 섹션 유형 정의서

웹페이지를 만들 때 쓰는 공통 언어. 페이지는 유형으로 나누고, 유형은 섹션의 조합으로, 섹션은 표현 변형으로 정의한다. 행사 랜딩은 SK MBM 랜딩페이지(디자인 씨드)로 실제 구현까지 연결했다.

순서: 페이지 유형 → 섹션 유형 → 표현 변형 → 행사 랜딩 12섹션

01페이지 유형 정의 — 10종

페이지를 목적에 따라 10가지로 나눈다. 유형을 정하면 기본 골격이 깔리고, 내용은 브리프와 첨부 자료로 채운다. 굵은 글씨가 대표 섹션.

02섹션 유형 정의 — 23종

페이지를 이루는 최소 단위. 스타일이 달라도 섹션의 이름과 역할은 같다. 스타일에 없는 유형은 비슷한 유형으로 대체해 그린다.

03섹션 × 표현 변형 — 레이아웃 분류

변형별 레이아웃 뼈대. 색과 폰트는 스타일이 입히므로 여기서는 구조만 본다(그린 = CTA·강조 위치). 내용에 맞는 변형을 고른다. 제품 화면이 강점이면 hero:screenshot, 기능이 많으면 feature:bento.

04행사 랜딩페이지 정의 — 12섹션

행사(세미나·웨비나·컨퍼런스) 랜딩 한 장에 필요한 섹션 규격. 반복 여부, CTA, 데이터 필드까지 정한다. 기준 폭 1920. 마지막 열은 SK MBM 랜딩페이지(디자인 씨드)에서 실제로 쓴 섹션.
