# PPT 평가 척도 · 생성 규칙 (2026-07-30)

모든 PPT 팩(생성·템플릿·검수)의 기준 규칙서. 출처: 사용자 정의 평가 척도.
적용 층위 — **(P)** AI 생성 프롬프트에 주입, **(C)** 팩 코드/CSS로 강제, **(A)** pack-audit/수동 검수 항목.

## A. 구조와 서사 — 25점
- 한 장에 한 메시지. 두 개 이상이면 감점. **(P)**
- 제목만 이어 읽어도 논리가 성립하는가. **(P)**
- 챕터 분할이 청중의 질문 순서를 따르는가. **(P)**
- 분량이 발표 시간에 맞는가. (16:9 기준 장당 40~60초) **(A)**
- 첫 3장 안에 "왜 지금 이 이야기인가"가 나오는가. **(P)**
- 마지막 장에 다음 행동이 명시되는가. **(P)**

## B. 시스템 일관성 — 20점
- 요소 클래스별 레이아웃 정의(표지·간지·목차·본문·데이터·비교·엔딩). **(C — 팩 타입 체계)**
- 타이틀 위치·크기·행간 픽셀 단위 동일. **(C — 팩 토큰)**
- 배경색 2개 이하, 액센트 1개(챕터당). **(C)**
- 카드·라인·여백 규칙 페이지마다 재발명 금지. **(C)**
- 페이지 넘버·러닝헤드 규칙적 부착. **(C — 네비 스트립·페이지 번호)**

## C. 타이포그래피 — 15점
- 1920 기준 24px(=팩 1280 기준 16px) 미만 없음. 본문 28px(≈19px) 이상 권장. **(C)**
- 위계 3~4단, 단 간 차이 1.3배 이상. **(C — 타입 스케일)**
- 줄바꿈은 의미 단위 — 어절 중간 줄바꿈 금지. **(C — 전 팩 `word-break:keep-all` 적용됨)**
- 크기별 자간 보정(큰 타입 타이트, 작은 타입 중립). **(C)**
- 줄길이 45~75자. **(P/C — max-width)**
- 서체 1~2종. **(C — Pretendard 단일)**

## D. 리듬과 밀도 — 15점
- 연속 3장이 같은 골격 반복 금지. **(P)**
- 풀블리드·타입온리·데이터 페이지 혼합으로 호흡. **(P)**
- 여백이 결과가 아니라 의도인가. **(A)**
- 빈 느낌을 요소로 메우지 않았는가(그건 레이아웃 문제). **(A)**
- 밀도 높은 장 뒤에 숨 쉬는 장. **(P)**

## E. 증거와 데이터 — 10점
- 주장마다 캡처·수치·출처. **(P — footnote 필드)**
- 데이터 그래픽이 실제 정보량을 가질 것 — 장식용 숫자·게이지 감점. **(P — 근거 없는 수치 금지)**
- 차트가 비교 축을 정확히 표시. **(C)**
- 추정과 확정 구분 표기. **(P)**

## F. 그래픽 완성도 — 10점
- 일러스트·다이어그램 단일 조형 언어(선 굵기·모서리·투영각). **(C — 팩 그래픽 시스템)**
- 그리드·정렬 실측. **(C/A — pack-audit 원본 대조)**
- 광학적 정렬 보정. **(A)**
- 클리셰 금지: 강한 그라디언트, 이모지, 좌측 보더 액센트 카드, 스톡 3D 아이콘. **(C/P — 이모지 금지 프롬프트 반영됨)**

## G. 기술 위생 — 5점
- 오버플로·클리핑 0. **(C — __clampSlide)**
- 폰트 대체 시 레이아웃 유지. **(C — export-pptx 줄바꿈 방어)**
- PDF·PPTX·프로젝터 동일 표시. **(A — 추출 정합 검증 절차)**
- 스피커 노트 전 페이지 존재. **(향후 — notes 필드 미지원)**
- 본문 대비 4.5:1 이상. **(C — 토큰)**

## 템플릿 추가 항목
- 확장성 — 텍스트 2배·항목 3→5개에도 버티는가. **(C — 자동 1단/2단, cols 가변)**
- 오용 방어 — 아무 내용을 넣어도 못 망치게. **(C — 팩이 디자인 전담)**
- 인수 가능성 — 설명 없이 규칙 파악, 페이지 복제로 새 장. **(C — 타입 카탈로그)**
- 브랜드 적합성 — 조직의 톤. **(A)**
