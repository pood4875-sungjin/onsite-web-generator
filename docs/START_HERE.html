— 5분 시작 가이드

MIDAS DRS(AX Design Generator) — 자료를 넣으면 AI가 PPT 장표·랜딩 웹사이트·eDM을 회사 스타일로 만들어 주고, 그 자리에서 편집·번역·PPTX 파일 내려받기까지 되는 웹 도구입니다. 코드를 몰라도 됩니다. 아래 순서대로 따라오시면 5분이면 직접 돌려볼 수 있어요.

읽는 순서 — 이 문서가 먼저입니다
1단계 → 2단계까지만 하면 핵심 기능이 전부 켜집니다(5분). 그다음 "작업 시작하기"로 클로드와 대화를 시작하시면 됩니다. 3단계와 GitHub 연결은 선택이고, 나중에 필요해질 때 하셔도 됩니다. 더 깊은 내용은 전부 인수인계 문서(docs/HANDOVER.html)에 있습니다.
먼저 알아둘 것 — AI는 지금 꺼져 있습니다
이 폴더에는 API 키가 들어 있지 않습니다. (API 키 = AI 회사에서 발급받는 이용권 번호. 이게 있어야 AI를 부를 수 있고, 쓴 만큼 그 번호로 요금이 청구됩니다.)
전달자가 일부러 자기 AI 연결을 끊고 넘겼기 때문입니다 — 안 끊으면 여러분이 테스트할 때마다 전달자 카드로 결제되니까요. 2단계에서 여러분 키를 붙이면 살아납니다.

AI 없이 화면부터 구경하기

AI가 꺼져 있어도 기존 프로젝트 열람·편집·PPTX 내려받기·스타일 구경은 전부 됩니다.

방법 A (권장) — 작은 서버를 띄워서 열기. 이 방식이 모든 기능이 정상 동작합니다.

  1. 터미널을 엽니다. (터미널 = 명령어를 글로 입력하는 창. 맥은 ⌘+Space → "터미널" 검색, 윈도우는 시작 메뉴에서 "PowerShell")
  2. cd 를 치고 한 칸 띄운 뒤, 이 폴더를 터미널 창에 끌어다 놓고 엔터. (폴더 경로가 자동으로 입력됩니다. 이게 "그 폴더로 이동하라"는 뜻이에요)
  3. 이어서 아래를 치고 엔터: 
    python3 serve.py
  4. 터미널에 "→ 브라우저에서 이 주소를 여세요" 라는 줄이 뜹니다 — 그 주소(보통 http://localhost:4788/app/index.html)를 브라우저 주소창에 입력하세요. (localhost = 인터넷이 아니라 내 컴퓨터 안이라는 뜻입니다. 남에게 공개되지 않아요. 4788 자리를 딴 프로그램이 쓰고 있으면 자동으로 다음 번호를 잡아서 알려줍니다 — 그래서 화면에 뜬 주소를 쓰는 게 정확합니다)

명령을 친 뒤 터미널이 멈춘 것처럼 보이면 정상입니다 — 서버가 켜져 있는 상태예요. 끄고 싶으면 Ctrl+C, 다시 쓰려면 3번부터 반복하시면 됩니다.

방법 B (더 간단하지만 제한적) — app/index.html 파일을 더블클릭해서 브라우저로 바로 열기. 간편하지만 일부 기능이 제한될 수 있습니다.

화면이 안 바뀌면 — 브라우저가 옛날 파일을 기억하는 것입니다
브라우저는 속도를 위해 한 번 본 파일을 저장해 둡니다(캐시). 그래서 파일을 고쳐도 화면이 그대로일 때가 있어요. 강력 새로고침으로 지웁니다 — ⌘+Shift+R (윈도우는 Ctrl+Shift+R).

내 키를 붙여서 생성 기능 살리기

Cloudflare 같은 서버 준비는 전혀 필요 없습니다. 키 하나면 됩니다.
  1. console.anthropic.com 에서 API 키를 발급받습니다 (sk-ant-로 시작하는 긴 문자열). 결제 수단 등록이 필요하고, 쓴 만큼 청구됩니다.

입력한 키는 이 컴퓨터의 브라우저 저장 공간(localStorage)에만 들어가고, 어디로도 전송되지 않습니다. 다른 분이 쓰려면 각자 자기 키를 넣으면 됩니다. 키를 채팅창이나 파일에 적어 두지 마세요.

작업 시작하기 — 클로드와 함께

이 프로젝트는 디자이너가 클로드(Claude Code)에게 한국어로 요청해서 만들어졌습니다. 같은 방식으로 이어가시면 됩니다. 폴더 안에 규칙서와 작업 절차서가 이미 들어 있어서, 클로드를 켜면 자동으로 읽고 그 규칙대로 작업합니다.

첫 마디는 이렇게 건네세요:

"docs/HANDOVER.html이랑 CLAUDE.md 읽고 이 프로젝트 파악해줘."

그 뒤로는 이런 식으로 말하면 됩니다. 개발 용어를 쓸 필요는 없습니다 — 원하는 결과와 조건만 말하면 돼요.

"이 PDF 스타일 그대로 새 PPT 팩 만들어줘. 소스에 있는 것만, 추측 금지."
"영어로 바꿨는데 버튼에 한국어가 남아 있어." — 증상만 말하면 원인을 찾아 줍니다
"방금 고친 거 실제로 되는지 검증해줘." — "될 겁니다"로 끝내지 않고 증거를 가져옵니다

더 많은 예문과 배경은 인수인계 문서(docs/HANDOVER.html)의 §3 인계자 가이드에 있습니다 — 그 절만 읽고 바로 시작해도 됩니다.

3단계 · AI를 아예 '탑재'하기 (선택 — 팀으로 쓸 때)

2단계와 뭐가 다른가요? — "입력"과 "탑재"의 차이
2단계(입력)는 키를 내 브라우저에만 기억시키는 방식입니다. 컴퓨터를 바꾸거나 다른 사람이 쓰면 각자 또 입력해야 하고, 발표 대본·AI 이미지·공유 링크는 안 됩니다.
3단계(탑재)는 키를 서비스 자체에 심는 방식입니다. 작은 중계 서버를 하나 세우고 그 안의 금고에 키를 넣어 두면, 누가 접속하든 키 입력 없이 전 기능이 돌아갑니다. 요금은 금고에 넣은 키의 주인에게 청구됩니다.

탑재 순서 (전체 그림)

  1. Cloudflare 가입 (무료)
  2. 중계 서버(워커) 올리기 — 이 폴더의 proxy/가 서버 설계도입니다. 내 계정 번호·보관함 번호로 갈아 끼우고 배포합니다 (갈아 끼울 자리는 파일 안에 YOUR_... 표시로 준비돼 있습니다)
  3. 금고에 키 2개 넣기 — 터미널에서 npx wrangler secret put ANTHROPIC_API_KEY 를 실행하면 입력창이 뜹니다. 거기에 키를 붙여넣으면 금고에 저장됩니다(Gemini 키도 같은 방식). 이 순간부터 키는 서버 안에만 존재하고, 파일이나 채팅 어디에도 남지 않습니다
  4. 앱과 서버 연결 — 배포하면 받는 서버 주소를 app/llm.js의 한 곳에 적어 줍니다(자리 표시돼 있음)
  5. (선택) 사이트도 인터넷에 올리기 — Cloudflare Pages로 배포하면 전 직원이 같은 주소로 접속합니다

가장 쉬운 방법: 위 순서를 외울 필요 없습니다. 이 폴더에서 클로드를 켜고 이렇게 말하면 처음부터 끝까지 같이 해 줍니다.

"docs/HANDOVER.html §13 보고, 내 Cloudflare 계정으로 AI 탑재(서버 세팅) 같이 하자."
API 키를 채팅창에 붙여넣지 마세요
키는 터미널 입력창이나 Cloudflare 대시보드에만 입력합니다. 클로드도 키를 요구하지 않도록 설정돼 있고, 대신 어떤 명령을 실행하면 되는지를 알려 줍니다.

내 GitHub에 올리기 (선택)

이 폴더에는 버전 관리(git) 연결이 없습니다 — 전달자의 GitHub 계정과 작업 이력이 전부 제거된 순수 파일 뭉치입니다. (버전 관리 = 작업을 저장해 두고 언제든 그 시점으로 되돌릴 수 있게 하는 것. 게임 세이브와 비슷합니다.) 시작하고 싶으시면 본인 계정으로 새로 연결하세요. 클로드에게 이렇게 말하면 같이 해 줍니다:

"이 폴더 git 시작하고 내 GitHub에 새 저장소로 올리는 것 도와줘."

직접 하시려면: git init → GitHub에서 새 저장소 만들기 → 안내대로 연결. 올리는 계정과 작성자 이름은 전부 본인 컴퓨터 설정을 따릅니다. 연결한 직후 git config core.hooksPath .githooks 한 줄을 실행해 두면 저장할 때마다 자동으로 오류를 잡아 주는 검수기도 켜집니다.

막히면

  • AI 생성이 안 될 때 — 설정 화면에 키가 저장돼 있는지 먼저 확인하세요. 그다음 클로드에게 "생성이 안 돼"라고 증상만 말하면 원인을 찾아 나갑니다. 추측해서 설명할 필요 없습니다.
  • 화면이 안 바뀔 때 — 강력 새로고침(⌘/Ctrl+Shift+R). 브라우저가 옛 파일을 기억하고 있는 경우가 대부분입니다.
  • 저장(커밋)이 막힐 때 — 자동 검수기가 문제를 잡아낸 것입니다. 고장이 아니라 정상 동작이에요. 터미널에 뜬 메시지를 그대로 클로드에게 보여 주면 고쳐 줍니다. (폴더를 내려받은 직후에는 git config core.hooksPath .githooks 를 1회 실행해 두세요.)
  • 그 밖에 뭐가 이상할 때 — 클로드에게 그냥 보이는 대로 말하세요. "글자가 얇아 보여", "이미지가 사라졌어" 같은 말이면 충분합니다.
