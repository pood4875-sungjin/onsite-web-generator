01과제 개요

과제명

웹사이트 빌더형 AX 디자인 제너레이터 구축·배포

과제 정의

기획 내용을 입력하면, 제너레이터가 사전에 정의된 디자인 시스템 / 컴포넌트 / 섹션 패턴 / 템플릿 구조를 기준으로 웹 페이지를 생성하는 도구를 구축한다. 우선 적용 대상은 온사이트 제품소개 페이지 및 매뉴얼 페이지로 설정한다.

초기 MVP는 완전 자동 생성 방식이 아니라, 정해진 템플릿 구조 안에 기획 내용을 입력하면 웹 페이지가 생성되는 방식으로 시작한다. 이후 고도화 단계에서는 AI가 기획 내용을 해석하고, 적합한 섹션 패턴을 자동으로 판단·조합하는 방식으로 확장한다.

02전체 개념

초기 MVP 구조

기획 내용 입력 ↓
정해진 템플릿 선택 (예: 제품소개 / 매뉴얼) ↓
템플릿에 맞는 입력 폼 작성 ↓
사전 구현된 섹션에 콘텐츠 자동 배치 ↓
HTML / CSS / JavaScript 조합 ↓
웹 페이지 미리보기 및 산출

11월 이후 고도화 구조

기획 내용 입력 ↓
AI가 콘텐츠 목적과 구조 해석 ↓
적합한 섹션 패턴 자동 선택 ↓
섹션 순서 자동 조합 ↓
웹 페이지 생성

초기에는 템플릿 기반 생성을 우선 구현하고, 이후에는 기획 기반 섹션 자동 판단으로 확장한다.

03핵심 구축 구조

제너레이터는 AI가 즉흥적으로 디자인하는 도구가 아니라, 정의된 블록을 조합하는 웹사이트 빌더형 도구로 구축한다.

구분역할산출물
Design System컬러, 타이포, 간격, 버튼, 카드 등 시각 기준 정의DESIGN_SYSTEM.md, tokens.css
Component Library버튼, 카드, 탭, 아코디언, 배지 등 기본 UI 구성components/
Section Pattern LibraryHero, Feature, Process, Manual, Blog, FAQ, CTA, Banner 등 웹 구성 단위 정의sections/
Template Preset제품소개/매뉴얼 페이지의 고정 구조 정의templates/product-intro.json, templates/manual.json
Content Schema기획 내용을 어떤 구조로 입력받을지 정의content-schema.json

04Claude/Codex 활용 방식 — 7월: 기준 정리 및 구조화

7월에는 Claude를 활용하여 디자인 시스템과 섹션 패턴을 문서화·구조화한다. 핵심은 "알아서 디자인해줘"가 아니라, 디자인 시스템 / 컴포넌트 / 섹션 패턴 / 콘텐츠 입력 구조를 AI가 읽을 수 있는 기준으로 정리하는 것이다.

7월 주요 작업

  • 디자인 시스템 기준 정리
  • Claude가 읽을 수 있는 MD 문서 구조화

058월: AI가 읽을 수 있는 코드 구조 구현

8월 Claude 테스트 방식

Claude에 디자인 시스템, 섹션 패턴, 컴포넌트 규칙, 템플릿 구조를 함께 제공하고, 온사이트 제품소개 페이지 콘텐츠를 입력했을 때 적절한 섹션과 콘텐츠 배치가 가능한지 검증한다.

예시 요청 첨부한 DESIGN_SYSTEM.md, SECTION_PATTERN.md, COMPONENT_RULE.md, productIntroTemplate.json을 기준으로 온사이트 제품소개 페이지 콘텐츠를 입력했을 때, 어떤 섹션에 어떤 콘텐츠가 배치되어야 하는지 JSON으로 만들어줘.

검증 포인트

검증 항목확인 내용
디자인 시스템 준수임의 컬러나 스타일을 생성하지 않는가
섹션 매핑콘텐츠가 적절한 섹션에 배치되는가
코드 재사용기존 컴포넌트와 섹션을 조합하는가
구조 안정성같은 입력에 대해 유사한 결과가 반복되는가
온사이트 적합성제품소개/매뉴얼 페이지 맥락에 맞는가

069월: 제너레이터 MVP 구축

9월에는 Claude에서 테스트하는 수준을 넘어, 내부 도구 형태의 제너레이터 MVP를 구축한다.

MVP 기능

기능설명
템플릿 선택제품소개 / 매뉴얼 페이지 중 선택
콘텐츠 입력제목, 설명, 기능, 단계, FAQ 등 입력
섹션 자동 배치정해진 템플릿 구조에 콘텐츠 삽입
미리보기생성된 웹 페이지 확인
코드 출력HTML/CSS/JS 또는 정적 웹 결과물 출력
온사이트 적용제품소개/매뉴얼 페이지 1차 완료

MVP 범위

9월 MVP에서는 자동 판단을 최소화한다.

사용자 입력 ↓ 정해진 템플릿 ↓ 정해진 섹션 ↓ 웹 페이지 생성

즉, 9월에는 AI가 모든 섹션을 알아서 선택하는 단계까지 확장하지 않고, 정해진 템플릿 구조 안에 기획 내용을 넣으면 웹으로 산출되는 것을 핵심 목표로 한다.

10핵심 정리

핵심 이 과제의 핵심은 AI가 자유롭게 웹사이트를 디자인하는 것이 아니라, 사전에 정의된 디자인 시스템 / 컴포넌트 / 섹션 패턴 / 템플릿 구조를 기반으로 웹 페이지를 안정적으로 생성하는 것이다.
7월 디자인 시스템 / 섹션 패턴 정의 및 디자인 ↓
8월 HTML/CSS/JS 코드화 + Claude/Codex 테스트 ↓
9월 정해진 템플릿 기반 제너레이터 MVP 구축 + 온사이트 적용 ↓
10월 안정화 및 내부 검증 ↓
11월 기획 기반 섹션 자동 판단 고도화 ↓
12월 페이지 유형 확장, 활용 가이드 배포, 최종 피드백 반영

최종적으로는 온사이트 제품소개·매뉴얼 페이지를 시작으로, 기획 입력만으로 브랜드/제품 기준에 맞는 웹 페이지를 빠르게 생성할 수 있는 웹사이트 빌더형 AX 디자인 제너레이터를 구축하는 것을 목표로 한다.
