웹 섹션 계약 한눈에

웹/랜딩 생성이 쓰는 섹션 어휘 · 페이지 유형 조립표 · 표현 변형 · 행사 필드를 실제 코드(app/pagetypes.js · 세미나 팩 4종)에서 그대로 뽑아 정리한 지도입니다. 맨 아래 §5에 고정형 배너 12블록 표와의 대조가 있습니다. 기준일 2026-08-12.

웹 팩은 두 갈래 — 랜딩형(Civil Blue·Ensol·Global MBM·Toss: 골격 고정, 글자·이미지만 교체, 섹션은 순서·숨김·추가만)과 사이트형(Saturn·KRDS·MIDAS AX·Aether Glass: 아래 어휘로 조립, 여러 페이지+GNB 연동). 이 문서의 §1~§3은 사이트형의 계약, §4는 랜딩형(행사)의 계약입니다.

01섹션 어휘 22종 — 팩이 구비하는 렌더러

각 팩은 이 어휘를 자기 디자인으로 구현. 없는 타입은 대체 순서(폴백)로 비슷한 걸 렌더 — 깨지지 않는 게 우선.

core 항상 · mid 중간 분량 이상 · rich 풍성 분량만. 굵은 것이 그 페이지의 대표(lead) 섹션.

동작: 페이지를 만들면 유형별 스캐폴드(기본 콘텐츠)가 깔려 빈 화면이 없고, AI(compose-web)가 브리프·첨부 근거로 실제 내용과 변형(variants)을 채운다. 대표 섹션은 pagehero가 표제를 대신하므로 자체 표제를 생략(중복 방지).

03표현 변형(variants) — 같은 섹션, 다른 얼굴

→ 전 변형 와이어프레임 카탈로그 보기 — 레이아웃 뼈대 그림 53장.
18개 섹션 × 2~4변형 = 총 47변형. AI 규칙: "콘텐츠 성격에 맞게 — 제품 화면 강조면 hero:screenshot, 기능 많으면 feature:bento. 페이지마다 똑같은 조합 반복 금지." 팩이 미구현인 변형은 기본형으로 렌더(깨짐 금지).

04행사(세미나) 필드 — 랜딩형 팩의 데이터 계약

세미나 팩 4종(mbm·axday·toss·orbit)이 소비. AI가 첨부 기획서에서 그대로 추출한다.

필드내용비고

섹션 컨트롤순서변경 · 숨김 · 추가X_SECTION_SPEC으로 앱에 노출

05고정형 배너 12블록 표와의 대조

네가 가져온 표(1920×유동 이벤트 페이지 블록 규격) ↔ 이 시스템. 있음 그대로 대응 · 부분 비슷하나 속성 차이 · 신규 어휘에 없음.

#표의 블록대응 어휘판정차이·메모
1Hero 배너hero있음title·subtitle·date·location·cta — 1:1
2띠배너 (Marquee)—신규흐르는 전광판 텍스트 — 어휘·팩 모두 없음
3소개영역 (Intro)intro·overview있음
4핵심포인트 (Key Point)feature·infocards부분반복 카드는 있음 — 카드별 CTA 선택 삽입은 없음
5이벤트 (혜택·경품)—신규프로모션 하이라이트 섹션 — notice와 성격 다름
6연사소개 (Speaker)speakers있음name·role·desc·photo — 1:1
7아젠다 (Agenda)agenda·sessions[]있음time·title·speaker — 1:1
8행사요약 (Event Summary)overview points있음대상·장소·일정 포인트로 대응
9신청 양식 (Registration)form부분폼 UI는 있으나 정적 데모 — 표의 submit_type·success_msg(실제 제출·완료 처리)는 서버가 필요한 신규 계약
10장소안내 (Location)axday 팩 내 표+지도 핀부분공용 어휘엔 없음 — map_image·parking_info 미지원
11질문답변 (FAQ)faq있음q·a 반복 — 1:1
12안내문구 (Info)notice있음title·text_list — 1:1
요약 — 12블록 중 7개는 그대로 있음, 3개는 부분(카드 CTA · 실제 제출 폼 · 장소 섹션), 2개는 신규(띠배너 · 이벤트 프로모션). 블록보다 큰 차이는 계약 2가지: ① 표는 폼이 실제 제출되는 걸 전제(현재는 데모 — 서버 수신이 필요) ② 반복(1~N)·CTA 유무를 블록 속성으로 명시(현재는 섹션 종류에 내재). 이 표대로 가려면: 어휘에 marquee·event·location 추가 + 카드 CTA 옵션 + 폼 제출 계약이 작업 단위다.
