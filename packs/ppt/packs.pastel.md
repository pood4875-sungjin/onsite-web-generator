# pastel — Pastel Gradient (PPT)

1. **정체** — 삼성화재 Pastel 19장 실측. 파스텔 그라데이션 키밴드·pg- 접두. naver 24타입 어휘 + 팔레트 4종(블루→틸→그린→코랄→딥블루 챕터 자동).
2. **상태** — 활성 — 시연 중 PPT 피커에서 machine으로 교체돼 숨김(복원=index PPT_VISIBLE 주석 참조).
3. 상세 계약·타입·함정은 팩 JS 상단 주석과 `docs/packs/README.md` 공통 포맷 참조. 주요 6팩 수준의 상세 문서가 필요해지면 같은 포맷(정체→상태→구성→데이터 계약→고정 요소→함정→배선)으로 확장할 것.
